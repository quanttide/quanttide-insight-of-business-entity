# 量潮咨询洞察

在量潮咨询业务中产生的洞察，沉淀咨询方法论与服务机制的机制性认知。

## 收录标准

insight 是对未来的预测，不是报告。每篇必须能一句话读出：我们预测 X，可被 Y 证伪，若真则改变 Z。写不出预测的不是洞察，是日志或散文，回 journal 去。

每篇的证伪时限写进文件头，到期重审：证实则升格进路线图，证伪则诚实标记并归因。证据压缩为一行来源链接，过程叙事全文留在 journal。
