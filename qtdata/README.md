# 量潮数据洞察

在量潮数据产品研发过程中产生的洞察。为 AI 写代码和写文档提供优质的基础上下文。

## 契约格式选择：CUE vs JSON

### 必须用 CUE

- 数据包含严格的类型约束（枚举值、正则模式、数值范围），且这些约束是跨端开发的接口契约
- 多处系统消费同一份数据，需要在定义层就杜绝格式错误，而非在运行时报错
- 典型场景：蓝图（定义 `#Step`、`#Pipeline`、`#Status` 等类型，先后被 `pseudocode submit`、`quotation create` 等 CLI 消费）

### JSON 就够

- 单次录入的业务表单，不需要跨系统共享同一份 schema
- 结构简单、字段含义自明，没有编译时类型校验需求
- 典型场景：需求规格、报价单

### 判断口诀

> CUE 是 schema 语言，管的是「定义层」；JSON 是数据格式，管的是「实例层」。需要约束定义时用 CUE，只需要存数据时用 JSON。
