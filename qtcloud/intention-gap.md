# 量潮云意图实现差距

对比量潮云意图（`data/intention/qtcloud`）与 qtcloud 应用实现。

## 意图要求

量潮云按五大云划分：数字资产云、执行云、写作云、客服云、创新管理。

- 数字资产云：资产全景图谱、Agent Harness 交付约束、资产定价
- 执行云：任务接收闭环，确认接收与升级机制
- 写作云：library、book、article 分层元数据
- 客服云：内外一体工单、无人值守、信任机制
- 创新管理：探索市场边界，而非自研

## 实现现状

- CLI：main 只输出一行文本，空壳
- Studio：事件目录、契约管理、流程编排三屏，数据来自静态 JSON

## 过时点

- 事件契约（publish、subscribe、schema）概念在意图文档中不存在，方向错位
- 五大云无一落地
- 全部为静态数据，无后端

## 行动建议

先对照意图对齐产品概念，再决定保留还是替换现有三屏。
