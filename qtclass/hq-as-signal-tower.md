# 总部不是权力中心，是信号发射塔

> 源自[机制设计思路](mechanism-design.md)第九节。总部只发信号、不收命令——市场语言替代管理语言。

## 传统总部 vs 信号塔

传统总部是命令中心：定战略、分任务、配资源、做考核，凭信息优势决策。量潮的总部"最大程度地提供上下文"——**只发信号，不收命令**。

## 关注即权力

"感兴趣程度 = 资源投入"。在这个模型里，总部唯一的权力是选择关注什么，而关注本身是不可替代的资源。候选人 sale 一个 demo 给总部，总部的选择全是信号：

- 冷处理（不关注）
- 观察（关注但不介入）
- 支持（关注 + 资源）
- 深度合作（关注 + 资源 + 参与）

候选人根据信号调整方向。总部不需要说"你应该做什么"，只需要说"我对这个感兴趣"——**市场语言替代管理语言**。

## 最激进的一点：总部公开承认自己也不知道答案

传统总部必须假装知道战略方向。量潮的总部说"公司希望找到规模化的方法"，让大家根据自己的角色自己去找——总部也在找答案，且公开承认。

这不是弱点，是最强的信号：候选人知道，如果自己找到了规模化方法，**自己就定义了公司的下一步**——不是在执行总部的战略，而是在帮总部发现战略。总部与候选人的关系不是上下级，是共生——总部提供上下文，候选人提供洞察，双方在不确定中共同演化。

## 迁移

- 组织设计：把"审批权"改写为"关注权"——预算、考核、指挥都可以让渡，唯独"关注什么"是组织注意力的宪法
- 平台运营：官方账号对内容的冷处理/观察/支持分级，等价于总部的信号发射
- 创始人角色：定义场域之后必须在场域之外（见 [founder-exit-from-operations](founder-exit-from-operations.md)）

## 边界

- 信号发射塔模型要求信号真实且稳定——关注与资源投入不一致会摧毁信号的可信度
- 法定职责（安全、合规、财务兜底）不能信号化，必须保留命令通道
