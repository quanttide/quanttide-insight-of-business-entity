# 招聘阻塞公告是一份战略升级的出生证明

> 基于 2026-09 初《关于招聘处理阻塞的解释和课堂免费学员报名建议》（brochure/qtclass/learn/free.md）的预测分析。该文表面是运营说明（招聘过载、引导转课堂），实际是课堂业务从"培训产品"升格为"公司核心基础设施"的第一次结构表态。

**预测**：免费学员公告埋下的五重结构（选人管道/筛选压力/注意力分配/信用边界/内容获客）将在一个季度内全部制度化，可被 qtclass journal 的制度落地节奏证伪；若全部落地，课堂业务战略将从"卖课"升级为"人才漏斗运营"。

## 机制：五个被预测的战略升级

### 一、课堂升格为公司选人管道

"招聘考核与课堂考核并轨，通过课堂考核即为通过招聘考核"——课堂的身份从培训产品重定义为公司的正式选人管道。当获客与选人都必须经过这个入口，课堂就从成本中心变为战略资产。这预告了课堂作为三大战略支点之一的定位。

### 二、免费额度从成本变为筛选机制的燃料

"免费学员额度 5-10 人，动态变化，取决于实训基地自治能力"——名额稀缺不是成本控制，是筛选压力的设计：免费入口必须开着（漏斗够宽），名额必须少（筛选够严）。预测它会与负数职级体系（-3 纯学员 → 0 可入职）合流为自然淘汰机制。

### 三、优先级声明是注意力经济与代金券机制的前奏

"付费学员 > 免费学员 > 招聘申请者"——把注意力本身定义为可分配的稀缺资源：谁进入体系、以什么身份、获得多少注意力，由体系结构决定而非由请求决定。这是代金券机制的前身：注意力与激励的分配从创始人拍脑袋变成制度自动流转。

### 四、"不做付费实习"声明是组织信用产品化的边界自觉

先向市场声明实习证明不卖、标准统一（堵住企业合作场景下"付费买实习名额"的腐烂路径），再把证明发放制度化（规则进议事仓库、代表初审）——最终实习证明成为组织信用的载体而非商品。这与联盟层的"信用账户"同构：每份证明都在为公司信用体系积累资产。

### 五、文章本身就是"规模化获客"的第一次实操

把"招聘处理不过来"的尴尬处境公开写成内容（策展式透明：坦诚优先级排序、承认处理能力不足），反而把危机转译为课堂的信任资产与获客入口——不靠投放，靠把真实处境变成叙事。这验证了公司战略"规模化获客=把获客从人的关系变成体系的产出"的最小闭环：内容获客 → 内容变现的通道由此打开（后续的打赏渠道讨论是同一条线的延续）。

## 迁移

- **产品**：课堂官网的信息架构应按"人才漏斗"重述——入口（免费/付费双轨）→ 筛选（任务与考核）→ 出口（招聘/内推），而非课程列表
- **制度**：免费额度的动态调整应绑定可观测指标（实训基地自治能力、平台建设水平），而非人工拍板
- **跨域**：实习证明的发放规则归代表大会（delib），信用记录归执行云——课堂只是这些信用资产的产出场景之一

## 边界

- 本文分析的是一篇公告，公告的承诺不等于制度；五个升级以 qtclass journal 中对应制度实际运行为准
- "预测"不改变当期事实：招聘阻塞在制度建成前仍是真实的服务缺口
- 付费学员业务（一对一课时）与人才漏斗是并行的两条收入/价值线，漏斗逻辑不能覆盖付费业务的定价正当性
