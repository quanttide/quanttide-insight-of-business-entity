# 课堂门槛与招聘问卷的分野

> 基于 2026-09-06 战略对话：招聘考核有严格筛选标准能保证稳定漏斗，但课堂不设门槛则进来之后仍有问题——需要门槛，但不能与招聘同种。同期确认招聘现行规则是发问卷（准入问卷，roadmap qtrecurit 已有结构化开放性问卷设计）。

**预测**：课堂门槛不需要复制问卷模式——用"报名作业 + 入场任务"两层付出型门槛替代问卷，可被报名转化率与首任务完成率证伪；若问卷复用到课堂，问卷答卷将与真实投入脱钩（答卷好不来上课）。

## 机制：两种门槛筛的是不同投入品

**招聘门槛筛能力存量**——入职即干活，公司等不起，所以用事前验证：准入问卷考察责任心（结构化开放性问卷 + AI 挖掘分析），后续实战验证能力。

**课堂门槛筛投入意愿**——进课堂的人就是还没能力的人，为"没能力"设能力门槛是自我矛盾。课堂的产出依赖学员真实投入（时间、注意力、完成任务），而非现有能力，所以门槛应验证"会不会真的来"：

- **报名作业（信息成本）**：读指定公开材料 + 提交简短回执（读到了什么/想解决什么问题）——筛掉群发式投递者，材料都不读的人进来也不会学
- **入场任务（时间成本）**：完成一件有真实产出的入门任务（开源协作入门类），门槛设在"做完了"而非"做得多好"——筛掉只报名不动手的人，同时代金券机制自然衔接（完成发券，券的购买力第一次被体验）
- **自然淘汰（机会成本）**：免费额度稀缺 + deadline 退出 + 负数职级——门槛不是入口的墙，是全程的坡；入门槛只挡明显不来的人，真筛选发生在每一周

同构点：两种门槛都在验证"与体系协作的成本收益"——招聘验证现在的协作价值，课堂验证未来的协作价值。分野点：招聘的证据在答卷里（可以一次做完），课堂的证据在行为里（只能持续发生）。

## 问卷要不要复用到课堂：不复用，但借其方法论

**不复用的理由**：问卷是一次性陈述，课堂要验证的是持续行为——答卷能力与上课投入是两种特质，问卷答得好的人可能不来上课（答辩型选手与实干型学员的分野）。且课堂已有比问卷更强的筛选器：入场任务是行为样本，比自我陈述信度高。

**要借的内核**：qtrecurit 问卷设计的真正创新不是问卷这个形式，而是"**把标准外化成可作答的结构**"——开放性问题让候选人自我暴露，AI 挖掘分析让答案可比较。这个内核迁移到课堂就是报名作业的回执设计：问题要开放到无法背诵模板（"你读到的最反直觉的一点是什么"），且答案可被低成本比较。

**分工形态**：招聘问卷考察责任心与背景（人岗匹配），课堂报名作业考察阅读投入与问题意识（学习匹配）——两个工具、一套方法论、各自服务自己的漏斗。

## 迁移

- 产品：课堂报名流程设计为"读材料 → 交回执 → 领任务 → 完成即录取"，每一步的成本都在筛一种人
- 数据：报名作业的完成率、回执质量分布、入场任务完成率，是课堂漏斗的第一组可观测指标（先于任何问卷数据）
- 跨域：qtrecurit 的"标准外化 + AI 挖掘"方法论可复用到课堂回执分析，形式不复用

## 边界

- 付出型门槛对"有能力但不了解量潮"的高质量候选人有一道额外摩擦——需要靠公开内容（开源体系、案例页）先建立足够吸引，摩擦才不会劝退目标人群
- 免费额度稀缺时门槛三层全部生效；额度充裕时第三层（自然淘汰）自动松弛——门槛强度是额度的函数，不是常量
