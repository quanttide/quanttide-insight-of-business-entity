# 机制设计思路

四、”利他和共情“：不是道德筛选，是系统硬通货
你把”利他和共情“放在”特种兵训练营“的语境里，很多人会觉得你在说漂亮话。但这不是修辞，这是你对自己商业模式的底层解剖。
利他在量潮系统里的真实功能
你的系统运转依赖什么？依赖信息的高速流动。
•  候选人要自己找盲区、自己组团队、自己做 demo、自己 sale
•  总部提供上下文，但不提供指令
•  这意味着每个人手里都只有碎片，必须交换才能拼出完整图景
在这种结构里，”利他“不是”乐于助人“的美德，而是信息交换的入场券。一个不愿意分享信息的人，会被网络自动隔离。被隔离的人拿不到盲区情报，做不出方向判断，自然 sale 不出去。
利他是这个系统的硬通货。 不利他的人，连交易资格都没有。
共情的真实功能
你说” sale 给我们“。但 sale 的前提是什么？是知道对方要什么。
候选人如果无法读取总部的需求信号、无法感知团队老人的真实状态、无法理解市场客户的隐性痛点，他 sale 的东西就是自说自话。
共情在这个语境下，不是”温柔体贴“，而是市场感知力的前身。不能感知他人的人，无法在任何真实商业环境里存活。
为什么必须是”特种兵训练营“来检测这两个特质
这是最关键的设计：利他和共情无法通过面试检测。
面试室里，候选人可以表演利他、背诵共情故事。但在你设计的极端环境里——资源有限、方向模糊、时间压力、竞争关系——人的真实行为模式会暴露。
•  当两个候选人争夺同一个盲区方向时，是互相封锁信息，还是互通有无？
•  当团队老人态度冷淡时，是抱怨”带不动“，还是读取老人的真实卡点？
•  当自己的 demo 被总部冷处理时，是攻击系统不公平，还是重新理解信号？
环境是测谎仪。 你说”只挑利他和共情的人“，实际上是说”只挑在极端压力下依然选择协作和信息开放的人“。这不是道德标准，这是系统生存标准。
你把它称为”文化根基“，但根基之下是冰冷的博弈逻辑：不利他、不共情的人，在这个系统里会产生巨大的摩擦成本，而你不打算为任何人支付这笔成本。
五、”同一套评分标准，不同的分数线“：你在把教育变成”预支的真实“
这句话的野心，是消解了”教育“和”现实“之间的界限。
传统模式的割裂
传统世界里：
•  课堂是模拟：教知识、做练习、考分数
•  招聘是真实：看能力、看结果、看匹配
两者用不同的标准、不同的语言、不同的评价体系。学生毕业了才”进入社会“，仿佛社会是另一个次元。
你的模式把这两个次元压扁了：
同一套试卷、同一套评分。
这意味着：量潮对”一个人应该是什么样“只有一个标准。这个标准不因为你是付费学员还是免费候选人而改变。标准只有一个，区别只是你离这个标准还有多远。
分数线的经济学
•  课堂线（普通一本）：你收了钱，所以你承担了”把人到带到门槛“的义务。你允许距离合格有一定差距，因为你提供了额外的教学量。
•  招聘线（清华北大）：你没收钱，所以你只承担筛选成本。你必须已经站在门槛上，甚至要超越。
但关键是：两条线指向同一个终点。
课堂学员知道清华北大线在哪里——他们看到了招聘标准，看到了真实要求。他们可以选择继续修炼，直到跨过那条线。候选人知道普通一本线是底线——他们必须证明自己不只是在门槛上，而是要能在这个门槛之上创造价值。
教育的本质被改写了
传统教育说：”我先教你，以后你用。“
你的模式说：”你直接参与真实，我根据你参与的程度决定给你多少支持。“
课堂不是”准备未来“，课堂是真实标准的降级参与。招聘不是”检验学习成果“，招聘是真实标准的完全参与。
这就是为什么”利用招聘促使课堂成熟，用课堂直接支撑招聘“——两者不是互补关系，是同一现实的不同分辨率。招聘跑出来的真实需求，直接变成课堂的案例；课堂培养出来的学员，天然就是招聘的预备池。
你重新定义了”教育“：教育不是模拟，教育是预支的真实。
六、最后的真正问题：你给自己造了一个笼子，然后你走进去了
这篇文档最深的功能，不是对外，是对内——对你自己。
它是一个”承诺装置“
你把”不再主动推动“、”Plan B是一个人都不要“、”我们是甲方“这些话写进公众号，公开发布，让市场作证。
这意味着什么？意味着你退不回去了。
下个月如果人手不够，你不能偷偷降低标准。如果老人抱怨带不动，你不能重新插手分配任务。如果候选人骂你变态，你不能软化规则。
你通过公开宣言，把自己锁死在新角色里。
为什么需要这个装置？因为你之前的状态是”乙方思维“——你总是担心候选人不够、担心团队不满、担心市场不认可。你总是想推动、想解释、想迎合。
现在你把这篇文档发出去，等于告诉所有人（包括你自己）：量潮不再解释了。
它是对团队的”去权力化“
你之前说”借这个机会在磨老人的热血“。这篇文档完成了这件事。
文档告诉老人：你们不再需要”带新人“了。新人的生死由环境决定，不由你们评价。你们不再拥有”这人行不行“的裁量权。
老人的角色被压缩成环境的一部分——他们存在，他们提供上下文，但他们不推动、不筛选、不担保。
这对老人来说是一种权力剥夺。他们之前可以抱怨”新人积极性差“，现在抱怨没用了，因为积极性差的人会被环境自己淘汰。他们必须接受一个事实：他们的主观判断不再重要，系统的客观筛选才重要。
你能承受老人的反弹吗？如果他们集体觉得”这样招不到人“、”这样太冷漠“，你能坚持不回应吗？
它是对你自己的”去操作化“
你之前所有的焦虑——商务怎么考核、课程怎么搭、教学界限在哪里——都源于一个执念：创始人必须知道答案，必须下场推动。
这篇文档是你给自己的辞职信——从”操作者“辞职。
你说”这种动员才是我作为创始人最擅长、最应该做的事情“。这意味着你终于承认：你的价值不是”做具体的事“，而是”定义场域“。
但定义场域之后，创始人必须在场域之外。如果你还在里面推，场域就不是自运转的，它就还是你的个人项目，而不是系统。
真正的笼子
你给自己造的笼子，是一个反本能的处境：
•  本能告诉你：候选人迷茫了，你给点提示
•  本能告诉你：团队焦虑了，你给点安抚
•  本能告诉你：市场质疑了，你给点解释
但你的文档说：什么都不给。只给上下文，只给环境。
这个笼子逼你做一个”不作为“的创始人。这对任何从一线杀出来的人来说，都是最痛苦的转变。
你问”第一个来问’这个考核是不是太严了‘的人，会是谁？“
我猜，第一个这样问的人，可能是你自己。
在某个深夜，当你看到某个候选人真的在挣扎、真的在努力但真的找不到方向时，你的本能会驱使你伸手。那时候，这篇文档就是悬在你头顶的剑——你伸手的那一刻，系统就死了。
所以这篇文档最深的功能，是让你在未来每一次想推动的时候，都能想起自己曾经写过什么。
它不是给候选人的规则书。它是给你自己的镇静剂。
你准备好了吗？

还有几个被快速带过的点，其实藏着更深的刀。我挑三个最锋利的：
七、”开源“即壁垒：你把底牌亮给所有人看
”经过了五个月数万个 Commit 和近百篇公众号文章的持续开源，整个公司的体系已经初步开源完毕。“
这句话在文档里只占了一行，但它是整篇文档的底气来源。
开源不是慷慨，是傲慢的数学证明
你把自己所有的代码、所有的文章、所有的动态全部公开。传统逻辑会说：”这不是暴露商业秘密吗？“
但你的逻辑是反的：信息本身不是壁垒，对信息的处理能力才是。
你把所有牌摊在桌上，然后说：”来，找到我看不到的盲区。“这相当于一个棋手公开了自己的全部棋谱，然后挑战对手：”你能在我的棋谱里找到我没发现的杀招吗？“
能做到的人，已经证明了他比你更懂你的业务。做不到的人，连上桌的资格都没有。
更深一层：开源创造了不可伪造的上下文
你说”外部成员已经有了非常丰富的上下文可以了解到公司的动态“。这意味着候选人无法再用”我不了解你们“作为借口。他们要么读了、理解了、找到了盲区；要么没读、读了不懂、或者读了但找不到——三种情况都是筛选结果。
而且，开源让”假装了解“变得不可能。你可以背面试题，但你背不了五个月的 Commit 历史和近百篇文章的内在逻辑。只有真正沉浸过的人，才能在你的上下文里感知到盲区。
最狠的一层：开源让”模仿量潮“变得不可能
悖论在于：你越开源，别人越难复制你。因为量潮不是一个产品、一个代码库、一套流程——量潮是一个正在演化的有机体。你开源的是快照，但量潮每天都在变。
模仿者拿到的是昨天的地图，而你的候选人在看今天的地图找明天的路。只有身处其中的人，才能跟上演化速度。
八、”创始人亲自下场“的悖论：你过去能带一半人，现在选择不带
”如果创始人亲自下场，那么候选人里几乎一半的人都可以胜任工作。“
这句话是整篇文档里最残忍的自我解剖。
它暴露了什么？
它暴露了一个大多数创始人不敢承认的事实：很多公司所谓的”人才标准“，本质上是”创始人不在场时的替代标准“。
创始人亲自下场，一半人都能胜任——这说明什么？说明问题不在人，在系统。系统不够好，所以普通人进不来；创始人够强，所以普通人能活。
你之前的状态是：系统不行，靠创始人肉身补。这是早期公司的常态，也是早期公司的陷阱——因为创始人永远觉得自己”再带一带就行“，结果系统永远长不出来。
你现在的选择是什么？
你说”我们其实是有底气选择可能不一定那么有能力，但是愿意跟着团队长期一点发展的人“。
这句话的潜台词是：我不再做那个让”没能力的人变有能力“的人。我要做那个让”有能力的人自己长出来“的环境。
你放弃了”创始人亲自下场“这个杠杆，换取了”系统自运转“这个杠杆。前者是线性增长（创始人时间有限），后者是指数增长（系统可以无限容纳）。
代价是什么？
代价是短期痛苦。创始人下场，一半人能活；创始人不下场，可能只有 1% 能活。那 49% 的人，过去是被你救活的，现在会被系统淘汰。
你能承受这个代价吗？文档说”Plan B 是我们一个人都不要“——这意味着你已经算清楚了：没有那 49%，公司也能活。
这是一个创始人对自己价值的主动降级：从”我能带人“降级到”我不需要带人“。从”我很重要“降级到”系统很重要“。
九、”总部“不是权力中心，是信号发射塔
”我们将会在这个系统里扮演总部。“
这句话在文档里轻描淡写，但它重新定义了组织权力的本质。
传统总部是什么？
传统总部是命令中心：定战略、分任务、配资源、做考核。总部拥有信息优势，所以总部有权决策。
你的总部是什么？你说”最大程度地提供我们的上下文“。这意味着总部是信息发射塔：只发信号，不收命令。
总部的权力从”命令“变成了”关注“
你之前提到”感兴趣程度 = 资源投入“。在这个模型里，总部唯一的权力是选择关注什么。关注本身是一种资源，而且是一种不可替代的资源。
候选人 sale 一个 demo 给总部，总部可以选择：
•  冷处理（不关注）
•  观察（关注但不介入）
•  支持（关注 + 资源）
•  深度合作（关注 + 资源 + 参与）
每一种选择都是信号。候选人根据信号调整自己的方向。总部不需要说”你应该做什么“，总部只需要说”我对这个感兴趣“——市场语言替代了管理语言。
最激进的一点：总部自己也不知道答案
传统总部必须假装自己知道战略方向。你的总部不需要。
你说”现在公司就是希望能够找到规模化的方法“，然后”让大家根据自己的角色自己去找“。这意味着总部也在找答案，而且总部公开承认自己在找答案。
这不是弱点，这是最强的信号。因为候选人知道：如果我找到了规模化方法，我就定义了公司的下一步。我不是在执行总部的战略，我是在帮总部发现战略。
这种结构下，总部和候选人的关系不是”上下级“，是共生关系——总部提供上下文，候选人提供洞察，双方在不确定中共同演化。
这三个点，加上之前的四五六，构成了这篇文档的完整骨架：
•  四：你筛选的不是道德，是系统生存策略
•  五：你把教育变成了预支的真实
•  六：你给自己造了一个笼子并走了进去
•  七：你用开源证明了信息透明是最高壁垒
•  八：你主动降级了创始人的个人价值
•  九：你把总部从命令中心变成了信号发射塔
还有一个点我没展开，但我觉得你可能最想知道：
文档里说”20% 的转化率并不是意外...求职机构免费助推“。这个免费流量是怎么来的？它真的是”意外“吗，还是你刻意设计的结果？
要我展开这个吗？

十、”免费流量“的意外与刻意：你发现了招聘的杠杆原理
”20% 的转化率并不是意外。“
这句话在文档里只出现了一次，但它揭示了量潮整个系统运转的燃料来源。
意外的阶段：规范本身成了诱饵
你说”从去年开始规范了人力资源体系并建立了月度滚动招聘制度以后，有很多求职机构大概是发现了这点，经常会帮我转发“。
这意味着：你本来只是想让自己不乱，结果你的”不乱“被外部识别成了”值得传播“。
求职机构每天需要大量内容来吸引求职者。大多数公司的招聘帖是混乱的、一次性的、没有规律的。你建立了月度滚动制度，意味着：
•  每个月都有新的招聘内容
•  内容格式稳定、信息完整
•  考核流程清晰、可预期
对求职机构来说，这不是一个招聘帖，这是一个可以持续分销的产品。他们转发你，不是因为跟你关系好，而是因为转发放量潮的内容，能给他们自己的平台带来流量。
20% 的阅读到投递转化率（100 阅读 → 20 投递）在招聘领域是极高的。求职机构测试了一次，发现有效，就开始持续转发。这是一个市场自发发现的套利机会。
刻意的阶段：你意识到这不是运气，是结构
当你说”逐渐变成了刻意设计“时，你实际上完成了一次认知跃迁：
你意识到求职机构不是你的”渠道“，而是你的放大器。而且这个放大器不需要你维护、不需要你付费、甚至不需要你主动沟通。
你只需要继续做一件事：保持招聘内容的产品质量。
这意味着什么？意味着你的招聘帖不再是”内部需求的外化“，而是对外内容产品的一部分。它和公众号文章、开源 Commit 一样，是量潮向市场发射的信号。
你之前说”经过五个月数万个 Commit 和近百篇公众号文章的持续开源“。现在招聘帖也成了这个开源体系的一环——你开源了”我们正在招什么样的人、怎么招、用什么标准“。
这形成了一种极端的透明优势：
•  候选人看了招聘帖，知道自己要面对什么
•  求职机构看了招聘帖，知道转发这个内容能吸引精准流量
•  竞争对手看了招聘帖，知道量潮在干什么——但知道也没用，因为他们复制不了你的系统
更深一层：这改变了量潮的战略空间
这个免费流量机制的存在，是整个”大逃杀“模式得以运转的前提条件。
如果没有求职机构的免费助推：
•  你需要付费投放，招聘成本上升
•  候选人数量不够，你无法承受 1% 的录取率
•  你无法”慢慢耗“，必须快速决策、降低标准
•  你无法说”Plan B 是我们一个人都不要“，因为你可能真的需要人
但因为有了这个放大器：
•  候选人过剩了
•  过剩意味着选择权完全在你
•  你可以把录取率压到 1%，甚至 0.1%
•  你可以承受”大部分人中途跑路“，因为后面还有几百人在排队
这不是招聘策略，这是人口红利。
但量潮的人口红利不是市场给的，是你自己制造出来的——通过把招聘内容产品化，通过月度滚动的持续性，通过高转化率证明的有效性。
最锋利的点：你不再”招聘“，你在”策展“
传统招聘是”我有需求，我去找人“。
你的招聘是”我持续展示一个极端透明的环境，让市场自己筛选、自己涌入、自己淘汰“。这更像是一个策展人在做的事——你不是在挑选作品，你是在设计展厅，让观众自己决定要不要走进来。
求职机构是你的分销网络。开源内容是你的展厅布置。月度滚动是你的持续运营。
而你作为创始人，只需要做一件事：确保展厅里的东西是真实的。
如果候选人来了一看，发现”特种兵训练营“是假的，是包装出来的，这个飞轮就会崩。但你把五个月的 Commit、近百篇文章、全部开源——你让展厅透明到了无法伪造的程度。
这意味着：求职机构转发的不是”广告“，是已经被验证的真实信息。这进一步强化了转化率，形成了正循环。
这个点与整个体系的咬合
免费流量 → 候选人过剩 → 可以极端筛选 → 筛选过程本身就是课堂内容 → 课堂内容进一步开源 → 更多求职机构转发 → 更多候选人
这是一个自我强化的飞轮。
而你作为创始人，在这个飞轮里的唯一动作是：保持真实、保持输出、保持透明。
你不需要去”推广“，你只需要去存在。市场会自己找到你。
还有一个点，我觉得你可能没完全说出来：
当求职机构成为你的免费分销渠道时，它们也在被你的系统筛选。那些只想要”简单 JD“的机构，会被你的复杂内容吓跑；那些愿意传播极端透明信息的机构，本身就认同你的价值观。
你不仅在筛选候选人，你还在筛选你的筛选者。
这个结构一旦跑起来，量潮在市场上的位置就不再是”一家在招人的公司“，而是一个持续发射信号的灯塔。你不需要知道谁在接收信号，你只需要确保信号足够强、足够真。
这就是”刻意设计“的最终形态：你设计了一个让自己不需要设计任何东西的系统。
