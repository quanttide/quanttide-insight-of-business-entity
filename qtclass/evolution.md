# 实训基地的演化

来源：journal qtclass/ 2026-08-26 ~ 09-04 结构化提炼（实录见 journal）

六天时间，实训基地从「公司的招聘群」演化成「有自己政府的独立主体」。这篇梳理演化的阶段、每一步的动力、以及演化方向。

## 演化时间线

### 一、训练场（8-26 ~ 8-27）

群是「指导窗口」：逐轮点评课题申请、甲方思维训练（「为什么这东西能帮我们赚钱」）、任务书按需发放。工作流程显性化：投递 → 准入问卷 → 加群 → 选题 → 申请 → 逐轮点评 → 实际产出。机制设计原则明确：企业服务市场需要什么，就设什么训练机制。

### 二、激励与筛选成制度（8-28 ~ 8-29）

- 代金券首次执行（章程评论奖励 + 兑换价目表）——承诺变成可执行的制度
- 负数职级体系：-3 纯学员 → -2 可小贡献 → -1 可较独立贡献 → 0 可入职——「商场地下楼层」，进度条可见
- 首个课题通过初审（需求澄清智能体）——「社区在量潮积木上排列组合」的期望第一次被验证
- 代表计划萌芽：计划从考核积极分子中选代表，与公司共享评审权
- org.quanttide.com 上线——组织有了对外门户

### 三、文化定调与课题涌现（8-30 ~ 8-31）

- **乙方心态定调**：对「我能不能过」坚决说不——把公司当普通甲方、把自己当专业乙方
- 自然淘汰显性化：退群、被否两三轮即退出——真实困难当筛子
- 真实困难即考题：商务平台缺商务上下文，这个冷启动困境本身就是考题
- 课题涌现与搭伴：邮件流程结构化、共识链 PoC，「我做底座你做上层」的合作精神被公开表扬
- 小红书获客第一个信号、学习中心上线

### 四、治理建制（9-01 ~ 9-02）

- **代表大会制度正式建立**：两会制（公司代表大会任上议院）、四位初始代表、秘书长兼主席、一票否决很少用、让渡清单公布
- 初审权实际下放：第一位代表完成首个课题评审（双倍奖励）
- 秘书处任命：活跃学员任秘书，开通群管理权限——「自己发挥」
- 增长模型：ARR/LTV、运营唯一目标「转化学员」、运营权可让渡
- 晚间讨论首次形成理想氛围（可复现）；创始人把运营日志与方法论发进群——透明即漏斗

### 五、自主运行（9-03 ~ 9-04）

- 秘书自主行动：新人地图方案 → 当天改群公告 → 24 小时内产生众包第一单——授权后无需推动
- 代表评审双样本：9-03「通过」、9-04 第一次「退回修改」——治理长出牙齿，章程从文档变成法律
- 治理下放三大步：结项初审授权（议事范围扩大化）、证明签发下放、规则生成权（「你们自己定」）
- **审批序列反转**：Demo 先向代表大会提交、再给公司——从「公司的机制」变成「独立主体」（详见 [industry-education-integration.md](industry-education-integration.md)）

## 演化的动力机制

1. **问题驱动**：每次制度演进都由真实问题触发（新人迷路 → 地图；邮件状态猜不出 → 数据底座；评审量大 → 下放）——没有为设计而设计的机制
2. **权随能授**：先证明能力再给权利——先有专业评审示范，立法权随后才下放；信任是赚出来的
3. **公司兜底**：试错无风险，练习成本由公司承担——代表敢做决定的前提
4. **显性化习惯**：规则全部成文公开（章程、手册、日志、方法论）——新成员能读到全部上下文，降低治理参与门槛
5. **激励天然对齐**：组织问题 = 个人课题的选题池；运营效果可折算课题成果——不需要管理成本去协调激励
6. **产教同构**：每个治理动作同时是教学内容（评审即能力培养、协作摩擦即训练）——治理成本与教育收益是同一笔账

## 创始人角色的演化

指导者（逐轮点评，8 月底）→ 制度设计者（建代表大会，9-01）→ 命名者（「组织模式的精髓」，9-04）→ 相邻主体（先代表大会后公司，9-04）。当组织不需要创始人推动时，创始人的判断开始被制度化——代表用他的标准自查，不需要他在场。

## 演化的方向

主权要素逐个出现：审批序列 → 资质权 → 立法权 → 组织空间。8-30 的商业化悬念（这套模式到底该以什么形式商业化）显出答案的形状：**实训基地可能长成独立的经营主体，公司是它的第一个客户**。

待观察的成人礼：代表大会第一次做出公司不同意的决定时，两个主体如何处理冲突——那将检验「授权但兜底」的真实边界。
