# 免费流量的杠杆原理

> 源自[机制设计思路](mechanism-design.md)第十节。20% 的阅读到投递转化率不是意外——招聘内容产品化让求职机构成为免费分销网络，候选人过剩让极端筛选成为可能。

## 意外阶段：规范本身成了诱饵

"从去年开始规范人力资源体系并建立月度滚动招聘制度以后，有很多求职机构大概发现了这点，经常帮我转发。"本来只是想让自己不乱，结果"不乱"被外部识别成了值得传播。

求职机构每天需要大量内容吸引求职者，而大多数公司的招聘帖是混乱的、一次性的、没有规律的。月度滚动制度意味着：每月都有新内容、格式稳定信息完整、考核流程清晰可预期——**对求职机构来说这不是招聘帖，是可以持续分销的产品**。转发量潮不是因为关系好，而是转发放量潮的内容能给自己的平台带来流量。20% 的阅读投递转化率在招聘领域极高，机构测试一次发现有效就开始持续转发——市场自发发现的套利机会。

## 刻意阶段：从运气到结构

意识到求职机构不是"渠道"而是**放大器**——不需要维护、不需要付费、甚至不需要主动沟通，只需要保持招聘内容的产品质量。招聘帖不再是内部需求的外化，而是对外内容产品的一部分：和公众号文章、开源 Commit 一样，是量潮向市场发射的信号（见 [open-source-as-moat](open-source-as-moat.md)）。

极端透明优势：候选人看了知道自己要面对什么；求职机构看了知道转发有效；竞争对手看了知道量潮在干什么——但复制不了。

## 杠杆如何撑起极端筛选

免费流量机制是整个"大逃杀"模式的前提：

- 没有它：付费投放成本上升 → 候选人不足 → 无法承受 1% 录取率 → 无法"慢慢耗" → 必须降标准 → 说不出口"Plan B 是一个人都不要"
- 有了它：候选人过剩 → 选择权完全在己方 → 录取率可以压到 1% 甚至 0.1% → 承受得起大部分人中途跑路

量潮的人口红利不是市场给的，是自己制造的——招聘内容产品化、月度滚动的持续性、高转化率证明的有效性。

## 从"招聘"到"策展"

传统招聘是"我有需求，我去找人"；量潮的招聘是"持续展示一个极端透明的环境，让市场自己筛选、自己涌入、自己淘汰"——策展人不挑选作品，只设计展厅，让观众自己决定要不要走进来。求职机构是分销网络，开源内容是展厅布置，月度滚动是持续运营。创始人唯一的动作：**确保展厅里的东西是真实的**——如果"特种兵训练营"是包装出来的，飞轮立刻崩塌；而五个月的 Commit、近百篇文章的全面开源，让展厅透明到无法伪造。求职机构转发的不是广告，是已被验证的真实信息——正循环成立。

飞轮：免费流量 → 候选人过剩 → 极端筛选 → 筛选过程本身成为课堂内容 → 内容进一步开源 → 更多机构转发 → 更多候选人。创始人不需要"推广"，只需要存在。

## 深一层：筛选者也在被筛选

求职机构成为免费分销渠道时也在被系统筛选：只想要"简单 JD"的机构被复杂内容吓跑；愿意传播极端透明信息的机构，本身就认同这套价值观。**不仅在筛选候选人，还在筛选自己的筛选者。**

结构跑起来之后，量潮在市场上的位置不再是"一家在招人的公司"，而是持续发射信号的灯塔——不需要知道谁在接收信号，只需要确保信号足够强、足够真。这就是"刻意设计"的最终形态：设计一个让自己不需要设计任何东西的系统。

## 迁移

- 获客策略：把"找渠道"改写为"把内容做成渠道愿意分销的产品"——产品化的标准是对方的商业模式能从中获利
- 闭环设计：筛选过程的公开本身构成内容供给，与 [recruitment-crisis-as-funnel-strategy](recruitment-crisis-as-funnel-strategy.md) 的漏斗战略互为印证

## 边界

- 杠杆的前提是转化率真实可验证——内容注水或筛选标准摇摆会同时摧毁机构分销意愿与候选人信任
- 极端筛选依赖"候选人过剩"，过剩依赖持续输出；输出中断则漏斗收窄，"Plan B"承诺将承受真实压力
