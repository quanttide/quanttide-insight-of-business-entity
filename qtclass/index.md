# 量潮课堂洞察索引

qtclass 洞察按四个主题组织：**定位**（课堂是什么）→ **机制**（怎么运转）→ **衡量**（怎么判断好坏）→ **演进**（往哪里去）。每篇独立成立，主题间互链。

## 定位：课堂是什么

- [classroom-as-innovation-lab.md](classroom-as-innovation-lab.md) — **课堂即创新实验室**：创新、教学、筛选三件事共用一个引擎；实训不是模拟创业，实训本身就是创业
- [professional-role-construction.md](professional-role-construction.md) — **课堂的核心在于构建职业角色**：技能是职业角色的副产品；产业要的是组织协作中的角色节点
- [industry-education-integration.md](industry-education-integration.md) — **产教融合的业务规律**：教育用真实业务当教材，产业用学习过程当交付；实训基地脱离公司——账本上多了一个主体

## 机制：怎么运转

- [selection-as-survival.md](selection-as-survival.md) — **筛选即系统生存策略**：利他共情不是道德筛选是系统硬通货；同一套评分标准不同的分数线；环境是测谎仪
- [open-source-as-moat.md](open-source-as-moat.md) — **开源即壁垒**：信息不是壁垒、处理能力才是；开源创造不可伪造的上下文，让模仿量潮不可能
- [hq-as-signal-tower.md](hq-as-signal-tower.md) — **总部不是权力中心，是信号发射塔**：市场语言替代管理语言；总部公开承认自己也在找答案
- [founder-exit-from-operations.md](founder-exit-from-operations.md) — **创始人退出操作**：公开宣言是承诺装置（把自己锁死在新角色里）；从"我能带人"降级到"系统很重要"
- [free-traffic-leverage.md](free-traffic-leverage.md) — **免费流量的杠杆原理**：招聘内容产品化 → 求职机构成为免费分销网络 → 候选人过剩 → 极端筛选成为可能
- [self-feedback.md](self-feedback.md) — **自反馈系统**：外部冲击驱动内部改进，系统压力替代管理压力

## 衡量：怎么判断好坏

- [benchmark-line.md](benchmark-line.md) — **基准线判断**：新系统效率超过已知系统时才具备规模化基础（课堂 vs 招聘的效率对比）
- [outcome-attribution.md](outcome-attribution.md) — **成果归因**：把组织效果追溯到产生它的动作上，让不可见的工作（运营/商务）获得度量衡

## 演进：往哪里去

- [recruitment-crisis-as-funnel-strategy.md](recruitment-crisis-as-funnel-strategy.md) — **招聘阻塞公告是漏斗战略的出生证明**：课堂从卖课升级为人才漏斗运营的五重结构预测
- [self-media-as-training.md](self-media-as-training.md) — **自媒体作为训练机制**：表达训练、市场训练、职业角色训练三合一；20% 提成让影响力归因成收入
- [intention-gap.md](intention-gap.md) — **意图实现差距**：现有 Studio 实现与自学平台定位相反，先回正再规划
