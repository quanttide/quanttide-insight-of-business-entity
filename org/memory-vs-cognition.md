# 记忆独立于认知

只建模推理框架无法获得智能，需要一个独立的外部记忆层承载经验。认知提供结构，记忆提供内容，智能是交汇的结果。

## 机制

- 推理框架解决「怎么想」，记忆层解决「根据什么想」，两者缺一不可
- 记忆不是推理的附属品，是独立资产，需要单独建设与维护
- 结构化框架与经验库必须分开管理，才能各自演进

## 迁移

- 第二大脑体系的理论基础：档案库是记忆层，章程与规格是认知层
- AI 系统设计：模型是认知，知识库是记忆
- 组织能力建设：方法论（认知）与案例库（记忆）分开沉淀

## 边界

- 记忆无结构则不可用，认知无内容则空洞，两者都要持续投入
- 记忆的迁移性高于认知：认知与组织绑定，记忆可以跨域复用
